# Roadmap - Kalkulator IPK

Sprint 1 (P09): charter, repositori proyek, README, dan satu pustaka UI (Bootstrap 5.3.3) dengan pembungkus ui-pustaka.js serta DEPENDENCIES.md. Roadmap ini diperbarui setiap minggu.

## P10 - Debug
* Fitur MVP: Must, hitung IPK.
* Deliverable: debug minimal 2 bug nyata pada perhitungan dan validasi isian.
* Bukti: minimal 2 commit fix:, cabang fix/..., dan merge ke main; tangkapan layar git log --graph.

## P11 - Modularisasi
* Fitur MVP: Must, simpan hasil dan riwayat.
* Deliverable: kode dipecah menjadi minimal 3 modul ES (src/hitung.js, src/penyimpanan.js, src/ui.js, src/main.js).
* Bukti: struktur folder src/ dan script type="module" di index.html.

## P12 - Komponen dan Rilis
* Fitur MVP: Should, tampilan nyaman di ponsel dan laptop; Could, target IPK.
* Deliverable: komponen reusable (baris mata kuliah, kartu riwayat), penyimpanan berversi yang aman, README dan CHANGELOG, tag v0.x.
* Bukti: tag v0.4.0, CHANGELOG.md, tangkapan layar tampilan 400 px.

## P13 - Konsep Produk
* Fitur MVP: seluruh fitur MVP.
* Deliverable: dokumen konsep produk (Tugas 7).
* Bukti: berkas Tugas 7 dan charter yang diperbarui.
